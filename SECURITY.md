# Security reporting

mcp_worker V2 is a source release candidate. A public security contact
and supported-release policy have not yet been approved. Until a private
reporting channel is established, report suspected vulnerabilities directly
to the repository owner/maintainer through an existing trusted private
channel. Do not post exploit details, credentials, Worker identity files,
private deployment URLs or sensitive logs in public issues.

Include the affected commit/version, operating system, a minimal
reproduction in an isolated environment, impact and suggested mitigation.
Do not test against deployments without authorization. If a credential
was exposed, revoke/rotate it and notify the affected owner promptly.

The owner must establish a private reporting channel and disclosure
process before publication. No response-time or remediation SLA is
promised. See [security model](docs/SECURITY_MODEL.md) for boundaries and
[release engineering](docs/RELEASE_ENGINEERING.md) for verification.
